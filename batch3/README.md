## 入选标准

与 batch2 一致，必须**同时**满足：

1. 提出 agent 系统 / AI 系统 / 模型
2. 有明确的、AI 可复现的 benchmark pipeline
3. **测试集公开可下载**（部分公开也算）
4. **评估可自动化** —— 排除湿实验、硬件测评、人工评测为主判据的
5. **论文中报告了可对比的 SOTA 数值**

## 本批构成

- **复刻优先级**：S 1 / A 29 / B 30
- **文章类型**：原创方法 60（无纯基准评测、无综述）
- **自动化等级**：全部为 A（有 ground truth 的客观指标，无一篇依赖 LLM-as-judge 或人评）
- **基准公开**：全部为「是」（均有直达链接或标准公开数据集）
- **SOTA 可对比性**：完整 56 / 部分 1 / 无可对比数值 3

剔除 C 档后，剩下 60 篇在自动化与基准公开两项上全部达标——这两项本就是复刻分的主要权重，
低分项都落进了 C 档。

## 版本说明

其中 **4 篇为 IEEE 早期访问版**（作者接收稿）。TPAMI 在正式排版前只发这个版本，
页眉是 IEEEtran 模板未填的 `JOURNAL OF LATEX CLASS FILES, VOL. 14, NO. 8`，
但有 IEEE 版权印记、无 arXiv 印记、正文完整——官方排版版此刻尚不存在，因此照收。
`fetch_state` 里以 `manual-dir/early-access` 标注，可追溯。

## 已知问题

**3 篇「无可对比数值」**：论文未给出可直接对比的跨方法数值，或数值只存在于图片表格中，
程序无法解析。可用 `SOTA可对比性` 列筛出，接入前需人工开 PDF 核表。
