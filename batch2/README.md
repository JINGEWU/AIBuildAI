## 入选标准

必须**同时**满足：

1. 提出 agent 系统 / AI 系统 / 模型
2. 有明确的、AI 可复现的 benchmark pipeline
3. **测试集公开可下载**（部分公开也算，如 29 个测试集里公开 10 个）
4. **评估可自动化** —— 排除湿实验、硬件测评、人工评测为主判据的
5. **论文中报告了可对比的 SOTA 数值**

## 复刻优先级

`可自动化等级(40) + 基准公开度(25) + SOTA标注(10) + 期刊影响力 + 链接与公开基准数 + 头顶空间大(12)`，
再扣除人评/湿实验/硬件依赖。分档：S ≥88，A ≥78，B ≥66。

本批共 **254 篇**：**S 16 / A 102 / B 136**。C 档按约定未抽取。

**自动化等级**：`A+` 可执行验证（单元测试/Pass@k）> `A` 有 ground truth 的客观指标 >
`B` 需 LLM-as-judge > `C` 需人评/湿实验/硬件（已全部排除）。

## 抽取原则

## 已知问题

- **14 篇「无可对比数值」**：论文本身未给出可直接对比的跨方法 SOTA 数值（或数值只在图/图片表中，程序无法解析），
  这类无法满足「跑同样测评对比其 SOTA」的要求，**接入前需人工开 PDF 核对**。可用 `SOTA可对比性` 列筛出。

- **8 篇 PDF 为 arXiv 版而非出版社官方版**（IEEE 不做金色 OA，官方版需机构权限）。
  benchmark 与 SOTA 信息两版一致，但引用时请注意版本：

## 值得优先看的几类

**"纠错型"论文** —— 证明既有 SOTA 数字不可信，直接决定你的基线怎么设：
`GEMS`（删掉蛋白信息仍有竞争力，说明是配体记忆）、`DirLinkBench`（简单 MLP 就到 80–90%）、
`PathoROB`（病理基座在学医学中心而非病理）、`PoseBench`（AF3 在 75% 以上情况下失败）、
`DIDgen`（训练集 MAE 低 ≠ 生成分布上可靠）

**效率型** —— 复刻门槛低：
`RETFound-Green`（算力少 400 倍）、`Rein++`（只训 0.4% 参数、24GB 显存）、
`TAMP`（5 张切片微调即超基线）

**超过硬基线**：
`FLOWR.ROOT`（超过 FEP+ 金标准）、`DMS-Fold`（88% 靶标优于 AlphaFold2）、
`GDRNPP`（纯 RGB 超过 RGB-D+ICP）、`Biomni-R0-8B`（8B 超过 Claude 4 Sonnet）
